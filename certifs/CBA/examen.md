## 2. Points à confirmer à la prochaine veille

- Nombre de questions, prérequis et langues : ouvrir la page CBA et sa FAQ sur `docs.linuxfoundation.org`
  (l'URL exacte de la FAQ CBA n'est pas apparue dans les résultats de recherche ; partir de l'index
  <https://docs.linuxfoundation.org/tc-docs/certification>).
- Version de Backstage visée par les questions : le PDF date d'octobre 2024, donc d'une version antérieure à celle de
  `versions.yaml`. Vérifier si la page officielle annonce une version ; sinon garder la double lecture ancien / nouveau
  système de backend prévue dans `objectifs.md` §4.
- `programme.md` indique `source_file: CBA.pdf` alors que le dépôt `cncf/curriculum` nomme le fichier `CBA_Curriculum.pdf` ;
  même écart que pour CAPA, à aligner dans `certifs/_sources_pdf/generer_programmes.py`.
- Prix : vérifier les promotions en cours avant d'acheter (bundles, Cyber Week, THRIVE-ONE).

## 3. Conséquences pour la préparation

- **Pas de documentation pendant l'épreuve** : les clés d'`app-config.yaml`, les commandes `backstage-cli`, les `kind`
  d'entité, les annotations standard et les noms de paquets (`@backstage/core-components`, `@backstage/backend-plugin-api`,
  `@mui/material`) doivent être mémorisés. Chaque fiche produit 10 à 20 flashcards
  (`revision/flashcards/plateforme-*.csv`) ; le quiz `revision/quiz/` et l'examen blanc `exams/` (prompt `06-examen-blanc.md`)
  reproduisent le format QCM à 90 min.
- **Un domaine pèse un tiers** : Customizing Backstage (32 %) suppose de lire et d'écrire du React et du TypeScript ;
  c'est la fiche la plus longue (`objectifs.md`, F3). Un apprenant venant de l'administration système doit y consacrer
  le temps prévu sans le rogner.
- **Deux systèmes de backend** : le programme date de 2024, l'examen peut citer l'ancien système ; `objectifs.md` §4
  impose une section « à connaître pour l'examen » dans les fiches concernées.
- **Jalon** : CBA se passe dans le même bloc que CNPA (`docs/prerequis.md`, parcours Golden Kubestronaut,
  nœud `plateforme_conf`). Fixer la date d'examen à la fin du bloc, comme mécanisme d'engagement (`docs/roadmap.md` §7).
- **Compte à rebours de validité** : 24 mois. Pour le Golden Kubestronaut, planifier CBA dans la rafale des associées
  après le bloc CKA/CKAD/CKS (`docs/roadmap.md` §7).
