## Compétences

### CBA-01 — Backstage Development Workflow (24 %)

- **CBA-01-01** Build and run Backstage projects locally
- **CBA-01-02** Understand local development workflows
- **CBA-01-03** Compile a Backstage project with TypeScript
- **CBA-01-04** Download and install dependencies for a Backstage project with NPM/Yarn
- **CBA-01-05** Use Docker to build a container image of a Backstage project

### CBA-02 — Backstage Catalog (22 %)

- **CBA-02-01** Understand how/why to use Backstage Catalog
- **CBA-02-02** Populate Backstage Catalog
- **CBA-02-03** Using annotations
- **CBA-02-04** Working with manually registered entity locations
- **CBA-02-05** Troubleshooting entity ingestion
- **CBA-02-06** Working with automated ingestion

### CBA-03 — Backstage Infrastructure (22 %)

- **CBA-03-01** Understand the Backstage framework
- **CBA-03-02** Configure Backstage
- **CBA-03-03** Deploy Backstage to production
- **CBA-03-04** Understand Backstage client-server architecture

### CBA-04 — Customizing Backstage (32 %)

- **CBA-04-01** Understand frontend versus backend plugins
- **CBA-04-02** Customizing Backstage plugins
- **CBA-04-03** Make changes to React code in Backstage App
- **CBA-04-04** Using Material UI components
