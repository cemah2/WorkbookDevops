## Compétences

### RHCE-01 — Be able to perform all tasks expected of a Red Hat Certified System Administrator

- **RHCE-01-01** Understand and use essential tools
- **RHCE-01-02** Operate running systems
- **RHCE-01-03** Configure local storage
- **RHCE-01-04** Create and configure file systems
- **RHCE-01-05** Deploy, configure, and maintain systems
- **RHCE-01-06** Manage users and groups
- **RHCE-01-07** Manage security
- **RHCE-01-08** Be able to analyze simple shell scripts

### RHCE-02 — Understand core components of Ansible

- **RHCE-02-01** Inventories
- **RHCE-02-02** Modules
- **RHCE-02-03** Variables
- **RHCE-02-04** Facts
- **RHCE-02-05** Loops
- **RHCE-02-06** Conditional tasks
- **RHCE-02-07** Plays
- **RHCE-02-08** Handling task failure
- **RHCE-02-09** Playbooks
- **RHCE-02-10** Configuration files
- **RHCE-02-11** Roles
- **RHCE-02-12** Use provided documentation to look up specific information about Ansible modules and commands

### RHCE-03 — Configure Ansible

- **RHCE-03-01** Create and modify the ansible.cfg configuration file
- **RHCE-03-02** Create and modify the ansible-navigator.yml configuration file
- **RHCE-03-03** Create a static host inventory file
- **RHCE-03-04** Define groups of hosts in static inventories

### RHCE-04 — Configure managed nodes

- **RHCE-04-01** Distribute SSH keys to managed nodes
- **RHCE-04-02** Configure privilege escalation on managed nodes

### RHCE-05 — Run playbooks

- **RHCE-05-01** Run playbooks with ansible-navigator and ansible-playbook
- **RHCE-05-02** Use ansible-navigator to discover modules and inspect content
- **RHCE-05-03** Create inventories and configure the execution environment

### RHCE-06 — Perform basic Git operations

- **RHCE-06-01** Clone Git repositories
- **RHCE-06-02** Add files to Git repositories

### RHCE-07 — Use Visual Studio Code

- **RHCE-07-01** Create playbooks and push them to a Git repository
- **RHCE-07-02** Configure ansible-navigator
- **RHCE-07-03** Run playbooks using development containers

### RHCE-08 — Create Ansible plays and playbooks

- **RHCE-08-01** Know how to work with commonly used Ansible modules
- **RHCE-08-02** Use variables to retrieve the results of running a command
- **RHCE-08-03** Use conditionals to control play execution
- **RHCE-08-04** Configure error handling
- **RHCE-08-05** Create playbooks to configure systems to a specified state

### RHCE-09 — Use roles and Ansible Content Collections

- **RHCE-09-01** Create and work with roles
- **RHCE-09-02** Install roles and use them in playbooks
- **RHCE-09-03** Install Content Collections and use them in playbooks

### RHCE-10 — Automate standard RHCSA tasks using Ansible modules

- **RHCE-10-01** Software packages and repositories
- **RHCE-10-02** Services
- **RHCE-10-03** Firewall rules
- **RHCE-10-04** File systems
- **RHCE-10-05** Storage devices
- **RHCE-10-06** File content
- **RHCE-10-07** Archiving
- **RHCE-10-08** Task scheduling
- **RHCE-10-09** Security
- **RHCE-10-10** Users and groups

### RHCE-11 — Manage content

- **RHCE-11-01** Create and use templates to create customized configuration files
- **RHCE-11-02** Use Ansible Vault in playbooks to protect sensitive data
