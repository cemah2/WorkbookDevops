# LFCS — Linux Foundation Certified System Administrator

Programme officiel retranscrit tel quel (en anglais). Les identifiants `LFCS-DD-CC` sont stables et servent au mapping objectifs → chapitres (`objectifs.md`).

## Notes

- Format : examen pratique en ligne, surveillé, 2 h. Distribution : non imposée par la page (vérifier le handbook du candidat avant l'examen).
- Validité : 2 ans. Fait partie du Golden Kubestronaut.

## Compétences

### LFCS-01 — Operations Deployment (25 %)

- **LFCS-01-01** Configure kernel parameters, persistent and non-persistent
- **LFCS-01-02** Diagnose, identify, manage, and troubleshoot processes and services
- **LFCS-01-03** Manage or schedule jobs for executing commands
- **LFCS-01-04** Search for, install, validate, and maintain software packages or repositories
- **LFCS-01-05** Recover from hardware, operating system, or filesystem failures
- **LFCS-01-06** Manage Virtual Machines (libvirt)
- **LFCS-01-07** Configure container engines, create and manage containers
- **LFCS-01-08** Create and enforce MAC using SELinux

### LFCS-02 — Networking (25 %)

- **LFCS-02-01** Configure IPv4 and IPv6 networking and hostname resolution
- **LFCS-02-02** Set and synchronize system time using time servers
- **LFCS-02-03** Monitor and troubleshoot networking
- **LFCS-02-04** Configure the OpenSSH server and client
- **LFCS-02-05** Configure packet filtering, port redirection, and NAT
- **LFCS-02-06** Configure static routing
- **LFCS-02-07** Configure bridge and bonding devices
- **LFCS-02-08** Implement reverse proxies and load balancers

### LFCS-03 — Storage (20 %)

- **LFCS-03-01** Configure and manage LVM storage
- **LFCS-03-02** Manage and configure the virtual file system
- **LFCS-03-03** Create, manage, and troubleshoot filesystems
- **LFCS-03-04** Use remote filesystems and network block devices
- **LFCS-03-05** Configure and manage swap space
- **LFCS-03-06** Configure filesystem automounters
- **LFCS-03-07** Monitor storage performance

### LFCS-04 — Essential Commands (20 %)

- **LFCS-04-01** Basic Git Operations
- **LFCS-04-02** Create, configure, and troubleshoot services
- **LFCS-04-03** Monitor and troubleshoot system performance and services
- **LFCS-04-04** Determine application and service specific constraints
- **LFCS-04-05** Troubleshoot diskspace issues
- **LFCS-04-06** Work with SSL certificates

### LFCS-05 — Users and Groups (10 %)

- **LFCS-05-01** Create and manage local user and group accounts
- **LFCS-05-02** Manage personal and system-wide environment profiles
- **LFCS-05-03** Configure user resource limits
- **LFCS-05-04** Configure and manage ACLs
- **LFCS-05-05** Configure the system to use LDAP user and group accounts
